# Roadmap

Phases describe order, not dates. A phase is done when its exit criteria are met, and none is committed to a calendar.

## Phase 1: Foundation

Public presence and honest data.

- [x] Public site at essence.onl
- [x] Live Robinhood Chain data: block, gas, block time, recent blocks
- [x] Chain TVL and pairs from public sources
- [x] Read-only wallet check
- [x] Brand identity and palette sampled from the source assets
- [x] Whitepaper, architecture and tokenomics documents
- [x] Contract slot and social links wired, inert until stated

**Exit:** the site reads live from the chain and every unstated item is visibly inactive.

## Phase 2: Launch

Stating the pieces that are still open.

- [ ] Announce the token contract address
- [ ] Publish supply, fees and allocation with on-chain proof
- [ ] Turn on the contract slot, chart and explorer links
- [ ] Announce official social accounts
- [ ] Narrow the pairs view to the Essence contract

**Exit:** every figure in [tokenomics](tokenomics.md) is stated and verifiable.

## Phase 3: The workforce

Making agent activity visible.

- [ ] Public record of agents and their activity
- [ ] Fees generated and distributed shown on the dashboard
- [ ] Activate the workforce section of the dashboard

**Exit:** anyone can trace activity from an agent to a distribution.

## Phase 4: Participation

Letting holders take part directly.

- [ ] Staking contracts published and reviewed
- [ ] Staking page enabled
- [ ] Holder position view

**Exit:** staking works end to end, and the contracts and their review are public.

## Phase 5: Growth

Widening the network.

- [ ] More agents and more kinds of work
- [ ] Open interfaces for builders
- [ ] Ongoing reviews and public reporting

## Reading this roadmap

Unchecked items are intentions. Order can change as information arrives. Changes are recorded here.
